# Vello UI Design Generation Prompt

You can use the following prompt in AI design tools (like Google Stitch, Midjourney, or DALL-E) to generate high-fidelity assets for the Vello project.

## The Prompt

"Create a comprehensive, production-ready high-fidelity UI design for a mobile messaging app named 'Vello', which is a direct, modern interpretation of WhatsApp. The design should follow Google's Material Design 3 guidelines and incorporate adaptive layouts for various screen sizes.

**Key screens to design:**
1. **Home Screen (Dashboard)**: Top app bar with search and menu; bottom navigation for 'Chats', 'Updates' (Status), and 'Calls'. Chat list includes profile pictures, message previews, and unread counters.
2. **Chat Detail Screen**: Conversational UI with an adaptive wallpaper background. Message bubbles distinguished between sent (#E2FFC7) and received (#FFFFFF). Rich input bar with emoji, attachment, and camera shortcuts.
3. **Profile & Settings UI**: Large profile picture with edit overlay, 'Name' field, 'About/Status' field, and phone number. Category-based settings list (Account, Privacy, Chats, etc.).
4. **Updates/Status & Calls**: List views matching WhatsApp's specific visual cues like status update rings and missed call indicators.

**Visual Style & Interactions:**
- **Color Palette**: WhatsApp greens (#075E54, #128C7E, #25D366) with Material 3 adaptive surfaces.
- **Animations**: Smooth shared element transitions, bouncy list animations, and morphing floating action buttons.
- **Adaptive**: Demonstrate the transition from phone (single-pane) to tablet (two-pane List-Detail) views."
